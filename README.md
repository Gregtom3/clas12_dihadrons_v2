# CLAS12 Dihadron Analysis

A C++ analysis suite for producing beam-spin asymmetries from CLAS12 dihadron data.

The initial scope covers RG-A data and Monte Carlo for the five pion-pair channels containing at most one neutral pion. The suite provides resumable batch processing, cached photon-identification models, sideband-corrected neutral-pion asymmetries, and uniform ROOT plots.

Development is led by Gregory Matousek.
